RegisterFarmUseCase Logic

Step-by-step what happens inside the use case

1

Validate Input

Farm name, admin name, phone, password — must all be non-blank. Email auto-generated as phone@mail.com.

2

Firebase Auth

Create Firebase Auth user with email+password. Returns UID.

3

Save FarmProfile

Write FarmProfile doc to Firestore with farm name, location, land area, adminUserId.

4

Save Admin User

Write User doc with role=ADMIN, farmId, phone, fullName. Farm is now operational.

Role-Based User Journeys

What each user type sees and can do, day-to-day

👑 ADMIN
Farm owner. Full access to everything including financial approval and staff management.
  • Register / setup farm
  • All 7 dashboard tabs
  • Approve farmer payouts
  • Add / deactivate staff
  • Configure SMS gateway
  • Setup land partitions
  • View all financial reports
🥛 DAIRY MAN
Operates the outer center. Records milk daily and manages farmers.
  • Record milk collections
  • Search / filter farmers
  • View FAT/SNF auto-rate
  • SMS status monitoring
  • Livestock view only
  • Khata view (read-only)
  • Cannot approve payouts
🌾 LABOUR
Field worker. Manages inventory and logs livestock health events.
  • Add / update inventory
  • Log fodder yields
  • Log biogas / waste
  • View livestock cards
  • Log health events
  • Cannot access Khata
  • Cannot record milk
🧑‍🌾 FARMER
Milk supplier. Read-only access to own milk ledger and dues.
  • View own milk records
  • View payment status
  • View dues summary
  • Receive SMS notifications
  • Cannot create entries
  • Cannot view other farmers
  • Cannot access livestock
